### 🚀 Projects

#### ⚡ ESP32-S3 Switchboard Automation
> WiFi-connected switchboard controller running a full web UI directly from the ESP32-S3 chip. Controls 7 GPIO outputs (monitors, amplifier, charger, extension cord) with live AJAX toggle controls — no page reloads, static IP, mobile-first UI served from the device itself.

**Stack:** C++ · ESP32-S3 · WebServer · WiFi · GPIO
🔗 [View on GitHub](https://github.com/HassanSardar1/esp32-S3-Automation)

---

#### 🌊 IIoT Water Quality Platform *(active — team project)*
> Edge-to-cloud industrial IoT pipeline for real-time water quality monitoring. ESP32 firmware over cellular → AWS MQTT broker → Laravel webhook gateway → dual-database storage (MySQL + InfluxDB) → Grafana dashboards. Modbus-RTU RS-485 integration with optical dissolved oxygen sensors.

**Stack:** MicroPython · Laravel · InfluxDB · MySQL · AWS IoT Core · Grafana · Modbus-RTU

---

#### 🛒 Ecommerce Platforms
